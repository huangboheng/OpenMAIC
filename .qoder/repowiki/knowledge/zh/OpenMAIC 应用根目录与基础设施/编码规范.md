- API Routes 每个功能域一个目录，目录下 route.ts 文件对应一个 HTTP 端点，保持路径即接口的映射关系。
- 客户端状态通过 Zustand store（useSettingsStore、useUserProfileStore 等）管理，组件通过 selector 订阅最小状态切片。
- 错误日志统一通过 `createLogger('模块名')` 创建 logger 实例，避免分散的 console.log。
- 国际化文案通过 `useI18n()` hook 的 `t()` 函数访问，禁止硬编码中文文本。
- 本地持久化使用 localStorage 配合 try/catch 容错，并在 useEffect 中做 hydration 以避免 SSR 不匹配。
