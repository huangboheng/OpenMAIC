- 采用 Next.js App Router：`app/layout.tsx` 作为根布局，通过 `ThemeProvider`、`I18nProvider`、`ServerProvidersInit`、`AccessCodeGuard` 等 Provider 包裹所有页面；`app/page.tsx` 是应用首页（课件上传与生成入口），`app/classroom/[id]/page.tsx` 为课堂详情页。
- API Routes 按功能域平铺在 `app/api/<domain>/route.ts` 下，每个路由文件独立处理 HTTP 请求，如 `chat`、`generate`、`export-video`、`pbl`、`classroom-media` 等，形成无状态的后端能力暴露层。
- 客户端组件集中在 `components/`，按场景划分为 slide-renderer、scene-renderers、edit、stage、chat、settings、ui 等子目录；业务逻辑库集中在 `lib/`，按 agent、orchestration、generation、edit、classroom、storage 等功能域划分。
- 依赖方向单向：页面 → components → lib/* → 外部服务（LLM/媒体/存储），API Routes 仅调用 lib/server 或第三方 SDK，不直接依赖 React 组件。
