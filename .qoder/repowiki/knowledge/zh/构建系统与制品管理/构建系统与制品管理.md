## 构建系统概览

OpenMAIC 采用 pnpm monorepo + Next.js App Router 的现代化前端构建体系，结合 Docker 多阶段镜像与 GitHub Actions CI/CD 流水线，实现从开发到部署的全链路自动化。

### 核心工具链

- 包管理器: pnpm 10.28.0（通过 packageManager 字段锁定版本）
- 运行时: Node.js >= 20.9.0（Docker 使用 node:22-alpine）
- 框架: Next.js 16.1.2，输出模式为 standalone（非 Vercel 环境）
- 工作区: pnpm-workspace.yaml 管理 packages/* 和 packages/@openmaic/*
- 构建脚本: 根 package.json 的 postinstall 自动按依赖顺序构建子包

### Monorepo 结构

项目包含多个独立可发布的 npm 包：
- @openmaic/dsl - DSL 定义与 schema 生成
- @openmaic/renderer - 渲染引擎
- @openmaic/importer - PPTX/PDF 导入器
- @openmaic/storage - 存储抽象层
- 第三方 vendored 包：mathml2omml、pptxgenjs

### 构建流程

本地开发:
```bash
pnpm install  # 触发 postinstall 自动构建所有子包
pnpm dev      # Next.js 开发服务器
```

生产构建:
```bash
pnpm build    # 执行 vendor 检查 + next build
```

测试套件:
- 单元测试: pnpm test (Vitest)
- E2E 测试: pnpm test:e2e (Playwright)
- 类型检查: npx tsc --noEmit

### Docker 容器化

主应用使用 4 阶段多阶段构建：
1. base: Node 22 Alpine + pnpm
2. deps: 安装依赖（包含 sharp、canvas 等原生模块编译工具）
3. builder: 执行 pnpm build 生成 .next/standalone
4. runner: 最小化运行镜像，以非 root 用户运行

渲染服务 (render-service/) 是独立的 Node.js 服务：
- 基于 Debian Bookworm（需要 glibc 支持 Chromium）
- 内置 Puppeteer + Chromium + FFmpeg
- 通过 iptables 实施出站网络隔离
- 可选启动（--profile video-export）

### CI/CD 流水线

GitHub Actions 包含三个主要工作流：

CI 流水线 (.github/workflows/ci.yml):
- Lint + Prettier 检查
- TypeScript 类型检查
- i18n 键值对齐检查
- 单元测试（根应用 + 各子包）
- Playwright E2E 测试

发布流水线 (.github/workflows/publish-packages.yml):
- 监听 main 分支推送或 @openmaic/*@* 标签
- 按拓扑顺序构建 dsl → renderer → importer
- 预发布质量门禁（test + typecheck）
- 生成 tarball 预览
- 使用 provenance 签名发布到 npm

文档构建 (.github/workflows/docs-build.yml):
- 独立构建 packages/docs 子应用

### 关键配置

Next.js 配置 (next.config.ts):
- 支持子路径部署（NEXT_PUBLIC_BASE_PATH）
- 生产环境启用 standalone 输出
- 安全头自动注入（CSP、HSTS、X-Frame-Options）
- 外部包优化（serverExternalPackages）

环境变量管理:
- .env.local 用于本地开发
- Docker Compose 管理服务间通信
- RENDER_SERVICE_URL 控制视频导出能力检测

### 开发者规范

1. 依赖管理: 使用 workspace:* 引用内部包，确保版本同步
2. 构建顺序: 遵循 postinstall 中的依赖拓扑顺序
3. 原生模块: sharp、@napi-rs/canvas 在 pnpm 中被忽略构建
4. Vendor 包: mathml2omml、pptxgenjs 保持精确版本锁定
5. 安全: render-service 通过 iptables 限制 Chromium 出站连接
6. 可观测性: 构建产物包含 source maps 和详细日志

### 特殊处理

- 动态导入绕过: maic-importer 通过静态文件复制绕过 Turbopack 的动态 require 限制
- 字体资源: 多语言字体通过 @fontsource 包管理
- 媒体处理: Sharp 用于图片优化，FFmpeg 用于视频导出
- 国际化: 提供 check:i18n-keys 脚本验证翻译键一致性
