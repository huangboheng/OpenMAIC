lib/ 目录采用按功能域划分的扁平结构，每个子目录对应一个独立业务能力：AI 编排（orchestration + agent）、课件生成（generation）、编辑器（edit + prosemirror）、课堂系统（classroom + chat + quiz）、渲染与导出（export + video-export + pdf）、存储层（storage + store）、媒体处理（media + media-parse + audio + playback）、工具与基础设施（utils + types + config + constants + contexts + hooks + i18n）。顶层入口文件 fetch-base-path.ts 提供子路径部署的 fetch 拦截器，logger.ts 提供统一日志工厂 createLogger(tag)。各模块之间通过 TypeScript 类型和函数接口解耦，不直接依赖 React 组件层（components/），由上层 app/ 和 components/ 组合使用。storage 模块通过 StorageProvider 接口抽象后端实现，默认 NoopStorageProvider 作为无外部存储时的降级；config/feature-flags.ts 集中管理 NEXT_PUBLIC_* 环境变量开关；generation/generation-pipeline.ts 作为 barrel re-export 聚合多阶段生成管线；orchestration/stateless-generate.ts 基于 LangGraph StateGraph 实现无状态多 Agent 编排，通过 partial-json + jsonrepair 流式解析结构化 JSON Array 输出。
