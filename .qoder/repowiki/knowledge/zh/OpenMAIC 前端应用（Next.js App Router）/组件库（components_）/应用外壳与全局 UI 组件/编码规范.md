- 所有组件文件顶部声明 `'use client'`，并通过 `@/lib/hooks/use-i18n` 的 `useI18n()` 获取 `t` 函数进行文案国际化。
- 组件通过解构方式从 Zustand store 中订阅最小状态切片（如 `useStageStore((s) => s.getCurrentScene())`），避免全量重渲染。
- 动画与显隐统一使用 `motion/react` 的 `AnimatePresence` + `motion.div`，配合 `initial/animate/exit` 属性描述过渡，保持视觉一致性。
- 对外暴露的组件通过 TypeScript 接口定义 props（如 `AccessCodeModalProps`、`HeaderProps`、`LanguageSwitcherProps`），并使用 `readonly` 标记不可变字段。
- 副作用组件（如 `ServerProvidersInit`）采用「无渲染纯副作用」模式：`return null`，仅在 `useEffect` 中触发 store 方法。
