- API 路由采用 Next.js Route Handlers 风格，每个功能目录内放置 route.ts 文件，路径即 URL 映射
- 客户端组件使用 'use client' 指令显式标记，服务端组件默认运行在服务端
- 状态管理统一通过 Zustand store（useSettingsStore、useUserProfileStore 等）在组件与 lib 间共享
- 日志输出通过 lib/logger 的 createLogger 实例化命名 logger，错误统一 toast 提示
- 国际化通过 useI18n hook 获取 t 函数，所有用户可见文本走 i18n key
