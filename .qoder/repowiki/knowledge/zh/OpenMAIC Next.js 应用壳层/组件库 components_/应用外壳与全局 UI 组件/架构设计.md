该模块是 Next.js 客户端组件集合，按功能域划分：
- 鉴权层：`access-code-guard.tsx` 作为路由包裹组件，通过 `/api/access-code/status` 判断是否需要 `AccessCodeModal` 输入访问码，失败时默认启用鉴权以保证安全。
- 舞台编排：`stage.tsx` 是课堂容器，基于 `useStageStore.mode` 在 `EditChromeRoot`（编辑）与 `PlaybackChromeRoot`（播放/自主）之间通过 `AnimatePresence` 做透明度交叉淡入淡出切换，并协调跨标签页编辑锁（`useEditModeLock`）、Pro 模式切换的 teardown 时序以及 `InteractiveIframeHost` 的生命周期保持。
- 头部与导航：`header.tsx` 仅负责返回按钮、当前场景标题和委托 `HeaderControls` 的 Pro Switch 控制。
- 国际化：`language-switcher.tsx` 基于 Radix `DropdownMenu` 提供语言切换，通过 `useI18n` 的 `setLocale` 更新全局 locale。
- 用户资料：`user-profile.tsx` 使用 `useUserProfileStore` 管理头像、昵称、简介，支持本地 Canvas 压缩上传与预设头像选择。
- 服务端初始化：`server-providers-init.tsx` 是无渲染副作用组件，挂载时调用 `useSettingsStore.fetchServerProviders` 拉取服务端配置。
依赖方向单向指向 `@/lib/store/*`、`@/lib/hooks/use-i18n`、`@/components/edit/*` 与 `@/components/ui/*`，不反向依赖业务页面。
