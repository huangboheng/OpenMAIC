OpenMAIC 项目使用自实现的轻量级 `logger.ts` 模块作为统一的日志系统，未引入第三方日志框架。该模块提供基于 tag 的命名空间化日志器，支持 debug/info/warn/error 四级日志级别，并通过环境变量控制输出格式与级别。

**核心机制**
- `createLogger(tag)` 工厂函数为每个模块创建独立命名的 logger 实例，tag 用于区分来源（如 'Chat API'、'ExportVideo Render API'）
- 日志级别通过 `LOG_LEVEL` 环境变量配置（默认 info），低于阈值的日志会被过滤
- 输出格式通过 `LOG_FORMAT` 环境变量切换：`json` 模式输出结构化 JSON 行，否则输出 `[timestamp] [LEVEL] [tag] message` 格式的文本行
- Error 对象自动提取 stack/message，其他非字符串参数通过 JSON.stringify 序列化

**使用模式**
- API 路由层广泛使用，每个 route.ts 文件顶部导入并创建模块级 logger 实例
- 前端组件（page.tsx、components/）同样使用该 logger，便于调试客户端行为
- 典型用法：`import { createLogger } from '@/lib/logger'; const log = createLogger('ModuleName'); log.info('message', data);`

**设计特点**
- 极简实现，仅 53 行代码，无外部依赖
- 直接调用 console.* 方法输出，不封装底层 I/O
- 支持运行时动态调整日志级别和格式
- 前后端共用同一 logger 实现，保证日志风格一致
